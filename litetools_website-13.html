✦ LiteTools

Simple file tools.
Right in your browser.

Compress images, resize pictures, convert to WebP, and optimize PDF files. No account needed.

Privacy: Your selected files are processed in your browser and are not sent to a LiteTools server. Avoid using this demo for highly sensitive files on a shared device.

Image compressor

Reduce JPG, PNG, or WebP file size.

Image resizer

Change an image's dimensions.

Convert image to WebP

Create a smaller WebP image for websites.

Basic PDF optimizer

Re-save a PDF with a compact file structure. This may not reduce scanned PDFs or PDFs containing large images.

PDF processing uses the open-source pdf-lib library loaded from a public CDN. An internet connection is needed for the library.

How to use LiteTools

Select a file in the relevant tool, adjust the settings if available, then tap the processing button and download the result. Results depend on the original file type and contents.

About

LiteTools is a simple independent browser-based utility project designed to help people perform common image and document tasks.

Privacy policy

LiteTools does not intentionally upload your selected files to its own server. Processing takes place in your browser. The website host may collect standard technical logs, and third-party libraries may be downloaded when a tool is used. Do not use this demo for confidential files on a device you do not trust.
